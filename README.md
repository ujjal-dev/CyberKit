## 📌 Overview

**Cyber CLI Toolkit** is a web-based platform designed to simplify the usage of popular cybersecurity command-line tools. Instead of memorizing complex commands and flags, users can generate them through an intuitive graphical interface.

This project is ideal for:

* 🎓 Cybersecurity students
* 🕵️ Ethical hackers
* 🐞 Bug bounty hunters
* 💻 Developers learning security tools

---

## 🎯 Objective

* Convert complex CLI commands into easy UI workflows
* Reduce human error in command usage
* Help users learn tools and flags interactively
* Provide ready-to-use commands instantly

---

## ⚙️ Features

### 🔧 Multi-Tool Command Generator

Supports multiple cybersecurity tools:

* SQL Injection → SQLmap
* Brute Force → Hydra
* Fuzzing → FFUF
* Directory Scanning → Gobuster / Dirsearch
* Web Vulnerability Scan → Nikto
* Subdomain Enumeration → Amass
* Reverse Shells → Netcat

---

### 🎛️ Interactive UI

* Input fields (URL, IP, ports)
* Dropdowns for attack types
* Toggle switches for flags
* File uploads (wordlists, hashes)

---

### ⚡ Real-Time Command Generation

* Dynamic command preview
* Updates instantly based on inputs

---

### 📋 Copy & Export

* One-click copy to clipboard
* Download commands as `.txt`
* Save commands (Local Storage)

---

### 🎨 Modern UI

* Dark hacker-style theme 😎
* Fully responsive design
* Smooth animations

---

### 📚 Educational Mode

* Explanation of each flag
* Tooltips and examples
* Beginner-friendly guidance
